## Target and non-negotiable boundaries

The completion target is one native headphone path:

```text
raw or containerized E-AC-3/JOC
  -> native E-AC-3 channel PCM
  -> native JOC/QMF/OAMD object reconstruction
  -> RenderScene + MetadataTimeline
  -> BS.2127 gains over a BS.2051 virtual-speaker layout
  -> static SOFA/BRIR binaural convolution
  -> stereo float PCM
  -> ordinary WASAPI stereo
```

- The Atmos runtime must not import FFmpeg/libav. FFmpeg remains the unchanged
  ordinary-player path and a development-only offline differential oracle.
- Stream DRC application is off. Do not add a limiter, automatic gain, loudness
  normalization, or hidden LFE attenuation to make a test sound acceptable.
- System Spatial Sound is off for the self-rendered stereo output. The optional
  Windows object bridge cannot complete this roadmap.
- Keep the existing ordinary PCM player, ASIO path, ALSA path, and dual-worker
  lifetime behavior unchanged until the offline chain is accepted.
- Unsupported syntax or renderer properties fail closed with a structured
  reason before self-rendered playback starts. Do not silently change renderer
  or decoder models in the middle of a track.
- Correctness starts at 48 kHz and with an identity listener. Other sample
  rates, head tracking, HOA, and multi-view are later capabilities.
- No CUDA dependency is planned. Start with scalar, deterministic reference
  math. SIMD is an optional measured optimization with a scalar fallback after
  correctness and real-time profiling are available.
